Here are five Chrome extensions that can make web development easier.

1. **Mobile Simulator**

   <img src="/post/extentions-chrome/mobile-simulator.png" alt="Screenshot of the Mobile Simulator Chrome extension" width={949} height={628} loading="lazy" decoding="async" />

   Want to see how your website looks on different devices and screen sizes? The **[Mobile Simulator](https://chromewebstore.google.com/detail/mobile-simulator-responsi/ckejmhbmlajgoklhgbapkiccekfoccmk)** extension lets you preview the responsive layout on phones, tablets, and even smart watches.

2. **WhatFont**

   <img src="/post/extentions-chrome/whatfont.png" alt="Screenshot of the WhatFont Chrome extension" width={853} height={608} loading="lazy" decoding="async" />

   Every web developer has wondered which font a website is using. **[WhatFont](https://chromewebstore.google.com/detail/whatfont/jabopobgcpjmedljpbcaablpmlmfcogm)** is an extension that shows you exactly that. Click any text on the page and it reveals the font family, weight, size, and line height.

3. **ColorZilla**

   <img src="/post/extentions-chrome/colorzilla.png" alt="Screenshot of the ColorZilla Chrome extension" width={2000} height={938} loading="lazy" decoding="async" />

   With **[ColorZilla](https://chromewebstore.google.com/detail/colorzilla/bhlhnicpbhignbdhedgjhgdocnmhomnp)** you can quickly grab the color code of anything on a website. Click the eyedropper icon, then pick the color you want from the page.

4. **Wappalyzer**

   <img src="/post/extentions-chrome/wappalyzer.png" alt="Screenshot of the Wappalyzer Chrome extension" width={1345} height={626} loading="lazy" decoding="async" />

   **[Wappalyzer](https://chromewebstore.google.com/detail/wappalyzer-technology-pro/gppongmhjkpfnbhagpmjfkannfbllamg)** makes it easy to see which technologies a website uses, including its frameworks, programming languages, hosting, and analytics tools.

5. **Lighthouse**

   <img src="/post/extentions-chrome/lighthouse.png" alt="Screenshot of the Lighthouse Chrome extension" width={1365} height={628} loading="lazy" decoding="async" />

   **[Lighthouse](https://chromewebstore.google.com/detail/lighthouse/blipmdconlkpinefehnmjammfjpmpbjk)** lets you test how well your website performs. It produces reports for performance, accessibility, best practices, and SEO so you know what to improve next.
