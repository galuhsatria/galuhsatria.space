Berikut adalah 5 Chrome Extensions yang dapat mempermudahmu dalam mengembangkan website.

1. **Mobile Simulator**

   <img src="/post/extentions-chrome/mobile-simulator.png" alt="Tangkapan layar ekstensi Chrome Mobile Simulator" width={949} height={628} loading="lazy" decoding="async" />

   Kamu ingin melihat tampilan website mu dari berbagai jenis device atau ukuran layar? Extension **[Mobile Simulator](https://chromewebstore.google.com/detail/mobile-simulator-responsi/ckejmhbmlajgoklhgbapkiccekfoccmk)** ini dapat kamu gunakan untuk melihat tampilan responsive website dari berbagai jenis device seperti smartphone, tablet bahkan smart watch.

2. **WhatFont**

   <img src="/post/extentions-chrome/whatfont.png" alt="Tangkapan layar ekstensi Chrome WhatFont" width={853} height={608} loading="lazy" decoding="async" />

   Pasti sebagai Web Developer pernah penasaran font apa yang dipakai di website yang sedang kita kunjungi. **[WhatFont](https://chromewebstore.google.com/detail/whatfont/jabopobgcpjmedljpbcaablpmlmfcogm)** adalah extension yang bisa kamu pakai untuk melihat font apa yang dipakai pada web tersebut. Tinggal klik pada text-nya maka akan muncul informasi detail font yang dipakai.

3. **ColorZilla**

   <img src="/post/extentions-chrome/colorzilla.png" alt="Tangkapan layar ekstensi Chrome ColorZilla" width={2000} height={938} loading="lazy" decoding="async" />

   Dengan **[ColorZilla](https://chromewebstore.google.com/detail/colorzilla/bhlhnicpbhignbdhedgjhgdocnmhomnp)** kamu dapat dengan mudah mengetahui kode warna dari suatu web. Tinggal klik icon eyedropper, lalu pilih warna yang kamu inginkan di website.

4. **Wappalyzer**

   <img src="/post/extentions-chrome/wappalyzer.png" alt="Tangkapan layar ekstensi Chrome Wappalyzer" width={1345} height={626} loading="lazy" decoding="async" />

   Dengan **[Wappalyzer](https://chromewebstore.google.com/detail/wappalyzer-technology-pro/gppongmhjkpfnbhagpmjfkannfbllamg)** kita dapat dengan mudah mengetahui teknologi yang digunakan pada suatu website, seperti framework dan bahasa pemrograman yang dipakai.

5. **Lighthouse**

   <img src="/post/extentions-chrome/lighthouse.png" alt="Tangkapan layar ekstensi Chrome Lighthouse" width={1365} height={628} loading="lazy" decoding="async" />

   **[Lighthouse](https://chromewebstore.google.com/detail/lighthouse/blipmdconlkpinefehnmjammfjpmpbjk)** memungkinkan kita untuk menguji kinerja dari website kita. Lighthouse dapat menghasilkan laporan seperti performance, accessibility, dan SEO dari website kita.
